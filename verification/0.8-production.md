## 보존과 증명 한계

- 기존 X 비밀 값과 STATE KV는 삭제하지 않았다. 새 0.8 감시는 X API를 호출하지 않는다.
- 운영의 인증 없는 `POST /run`은 전환 후 실제 요청에서 401이었다. 이는 공개 수동 실행이 막힘을 증명하며, 토큰이 있는 수동 진단이나 실제 메시지 전송 시험은 이번 전환에서 수행하지 않았다.
- 24시간 관측과 새 실제 공지의 전달 지연은 아직 검증하지 않았다. 시간 경과가 필요한 항목이며 이미 검증된 운영 적용 완료와 구별한다. 이 기간이 지나기 전 되돌리기용 자원을 정리하지 않는다.
- 지식 기록 범위는 current-project다. 이 미등록 프로젝트의 운영 상태를 사용자 전역 선호로 확대해 저장하지 않는다.
